# Glassmorphic Login Card

A modern, responsive glassmorphic login card built with pure HTML5, CSS3, and JavaScript, following **Hallmark** craft standards and adapted from **Uiverse Galaxy** micro-interactions.

## Features
- **Glassmorphic Surface:** Dark blue frosted glass container with `backdrop-filter: blur(20px)` and subtle hairline borders.
- **Atmospheric Background:** Fullscreen crisp multi-layered mountain vector illustration (`mountains.svg`) with deep-blue gradient fallback.
- **Micro-interactions:** 
  - Dynamic focus border line on input fields.
  - Scale & fade entry animation on load.
  - Smooth reverse scale-to-zero exit animation when clicking the close button (`X`).
  - Tactile button press effects.
- **Typography & Icons:** Powered by Google Fonts (Poppins) and Boxicons.
- **Accessibility:** Fully accessible with `:focus-visible` styling, reduced-motion fallback, and semantic markup.

## Project Structure
- `index.html` — Semantic markup and layout structure.
- `style.css` — Hallmark-compliant design tokens, glassmorphism styles, and animations.
- `script.js` — Form validation and dismissal/restore state handlers.
- `mountains.svg` — Bespoke SVG mountain landscape background.
